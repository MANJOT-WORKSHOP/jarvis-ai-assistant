# J.A.R.V.I.S — AI Assistant

An advanced AI desktop assistant with real-time speech interaction, Gemini vision integration, dynamic custom UI, and automated tools.

## Features
- **Voice & Speech**: Offline/online Edge-TTS, wake-word detection, and hotkey activation.
- **Vision & Multimodal**: Real-time screenshot and camera feed analysis with Gemini.
- **System Monitoring**: Live CPU, RAM, battery stats, and custom themes.
- **Command Handling**: Web navigation, application launching, weather, news, reminders, and notes.
